
# Sofia AI Studio

### Shaheed Bhagat Singh State University, Ferozepur

**Your AI. Your Ideas. Your Creation.**

Sofia AI Studio is an AI-powered development platform designed to help users create applications, websites, games and intelligent AI agents.

## Features

- AI chat and question answering
- AI image generation
- Voice input and output
- Image analysis
- File upload and analysis
- AI model configuration
- Temperature settings
- Chat history
- Project management
- AI agent builder
- Build Anything prompt interface
- Code editing and live preview
- Project export and downloads
- GitHub integration
- PWA installation support

## Technology Stack

- Next.js

- Tailwind CSS
- Puter AI

## Installation

Clone the repository:

    git clone https://github.com/sidhuanmoljatt-alt/Sbsu-ai-studio.git

Open the project:

    cd Sbsu-ai-studio

Install dependencies:

    npm install

Create your local environment file:

    cp .env.example .env.local

Start development:

    npm run dev

Open:

    http://localhost:3000

## Production Build

Run:

    npm run build

Start production server:

    npm run start

## Deployment

Sofia AI Studio is designed for deployment using Vercel.

1. Connect the GitHub repository to Vercel.
2. Select Next.js as the framework.
3. Configure required environment variables.
4. Deploy the application.
5. Test the production website.

## AI Services

Puter AI and other supported AI providers can be connected.

AI model availability, usage limits and pricing depend on the provider.

Users may supply their own API keys.

Never commit private API keys to GitHub.

## Security

- Keep private credentials on the server.
- Use environment variables for secrets.
- Validate uploaded files.
- Protect API routes.
- Authenticate users before accessing private projects.
