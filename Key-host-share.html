Pick a key above → Share. Creates a local share link with expiry. For real hosting, paste the generated JSON to your host.

How hosting works

This page never sends your keys to a server by itself. Generate Share Link creates a #share=... hash link you can send. The receiver opens it in their browser and the key is decoded locally. For a permanent hosted link, use the Export JSON and host it on GitHub Pages / Netlify / Vercel yourself.
