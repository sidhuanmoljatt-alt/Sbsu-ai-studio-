🗄 Supabase setup (free tier)

  1. Create a project at supabase.com → copy Project URL and anon key.
  2. Paste them below as SUPABASE_URL / SUPABASE_ANON_KEY (also in Vercel env when deploying).
  3. SQL editor → run: create table projects(id text primary key, name text, engine text, code text, updated timestamptz default now());
  4. Authentication → enable Email for Login/Signup. Projects sync automatically once keys are set; localStorage remains the offline fallback.
